### **1. Чистые функции (Pure Functions)**  
**Концепция:**  
Методы без побочных эффектов, не зависящие от внешнего состояния, всегда возвращающие одинаковый результат для одних аргументов.  

**Задание:**  
Реализуйте метод `List<Integer> squareList(List<Integer> numbers)`, который:  
- Принимает список целых чисел.  
- Возвращает новый список с квадратами чисел.  
- Не изменяет исходный список.  
- Не использует глобальные переменные или поля класса.  

**Критерии оценки:**  
- ✅ Метод не модифицирует входной список.  
- ✅ Нет ссылок на `this`, статические поля или внешние состояния.  
- ✅ Работает за O(n).  

**Вопросы для самооценки:**  
1. Почему изменение входного списка нарушает чистоту функции?  
2. Как проверить, что метод не имеет побочных эффектов?  
3. Что произойдет, если передать `null` в метод? Как это исправить?

### **2. Неизменяемость (Immutability)**  
**Концепция:**  
Объекты, чье состояние нельзя изменить после создания (через `final`, `record`, конструкторы).  

**Задание:**  
Создайте:  
1. `record Point(int x, int y)` для представления точки.  
2. Класс `ImmutableCircle`, использующий `Point` и `final double radius`.  
3. Метод `ImmutableCircle withRadius(double newRadius)`, возвращающий новый круг с обновленным радиусом.  

**Критерии оценки:**  
- ✅ Все поля `final`.  
- ✅ `withRadius` создает новый объект, а не изменяет текущий.  
- ✅ Использован `record` для `Point`.  

**Вопросы для самооценки:**

**Задание:**

